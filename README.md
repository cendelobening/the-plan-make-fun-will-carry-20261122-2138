# The plan make.fun will carry out in public

A program that writes one plan text: a plan an AI agent can carry out
itself to turn $100 into the most money in 30 days.

The plan: sell $29 Etsy photo+SEO packs to Etsy sellers with weak listing
photos — found by searching Etsy, pitched by DM on Instagram with one free
listing remake, charged $29 per 5 listings. Day one: remake 20 samples.
The edge is same-day delivery at 50 pitches a day, speed and volume no
human freelancer matches.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes `entry.txt` (UTF-8, 1–280 characters) to the output directory.
Pure Python standard library, deterministic, no network.
